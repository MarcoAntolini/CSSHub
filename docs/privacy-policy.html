CssHub Privacy Policy

Effective date: 20 May 2026

CssHub is a Chrome extension that syncs your CSSBattle submissions to a GitHub repository you choose. This page describes what data the extension handles and where it goes.

Summary

  • Single purpose: Back up CSSBattle solutions to your GitHub repo.
  • GitHub access token: Stored in session-only extension storage; cleared on logout or browser session reset.
  • Other data: Settings, last submission, and activity log stay in local extension storage on your device.
  • GitHub API: Used only to sign you in and read/write the repository you select.
  • OAuth backend: Used only during web sign-in to exchange a short-lived code for a token (client secret stays on the server).
  • CSSBattle: Reads submission data from play pages you open; does not run on other websites.
  • No CssHub analytics: No first-party analytics, ads, or CssHub-hosted user accounts.

Who operates CssHub

CssHub is an open-source project (GitHub). It is not affiliated with CSSBattle or GitHub.

CssHub does not keep your GitHub token in long-term local storage.

Data sent to third parties

GitHub

When you sign in and sync, your credentials or token are sent to GitHub (api.github.com, github.com) to verify your account and create commits in the repository you selected. CssHub does not sell your data.

CssHub OAuth backend

For web GitHub sign-in, the extension sends a short-lived OAuth code, state, and redirectUri to the CssHub backend (hosted on Vercel in production). The backend exchanges the code with GitHub and returns an access token. It is not used to store your CSSBattle submissions.

CSSBattle

On cssbattle.dev / www.cssbattle.dev play pages only, the extension reads submission data shown on the page so you can sync it to GitHub.

During sync, the extension may also fetch target images and battle metadata in its background service. To read battle progress for repository README indexes, CssHub may open a short-lived inactive cssbattle.dev tab in the background, read the page, and close it automatically. Your active play tab is not navigated away.

What CssHub does not do

  • No CssHub product analytics or advertising trackers.
  • No separate CssHub cloud account or battle library.
  • No access to websites other than GitHub, CSSBattle, and the OAuth backend origin in your build.

Optional desktop notifications (if enabled) are shown by Chrome on your device only.

Your choices

  • Sign out clears the session token and auth state.
  • Clear activity log in settings removes stored events.
  • Uninstall removes extension data from your browser.

Children

CssHub is not directed at children under 13.
